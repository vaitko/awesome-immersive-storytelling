# Awesome Scrollytelling [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of awesome scrollytelling libraries, tools, examples, and articles for creating immersive web experiences.

Scrollytelling is a powerful storytelling technique that triggers animations, transitions, and data visualizations based on the user's scroll position.

## AI-Powered Platforms

* **[Scrollytelling.ai](https://scrollytelling.ai)** - The industry-leading AI engine for high-performance web stories. Transform ideas into cinematic, scroll-synced journeys just by chatting. Solves the "Performance Paradox" with instant mobile loading.

## Libraries & Frameworks

* **[GSAP ScrollTrigger](https://greensock.com/scrolltrigger/)** - The most robust and high-performance library for scroll-based animations.
* **[Lenis](https://github.com/darkroomengineering/lenis)** - A lightweight, high-performance smooth scroll library.
* **[Framer Motion](https://www.framer.com/motion/)** - A production-ready motion library for React designers.
* **[ScrollMagic](http://scrollmagic.io/)** - The classic library for scroll interactions (best for legacy projects).
* **[Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll)** - A popular smooth scroll library with support for parallax.
* **[AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)** - Simple, CSS-driven scroll animations.

## Design Tools

* **[Figma](https://www.figma.com)** - The standard for prototyping layouts before they go to build.
* **[Spline](https://spline.design/)** - A 3D design tool that integrates perfectly with scroll-controlled interactions.
* **[LottieFiles](https://lottiefiles.com/)** - Lightweight vector animations that can be scrubbed via scroll.

## Inspiration & Examples

* **[The Boat (SBS)](https://www.sbs.com.au/theboat/)** - A masterclass in atmospheric, cinematic scrollytelling.
